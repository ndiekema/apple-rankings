# Pip launch catalog guidelines

## Scope

The first public catalog should focus on varieties that U.S. users can reasonably encounter: common grocery-store apples, familiar U.S. regional apples, heritage varieties, cooking apples, and U.S.-relevant cider apples. A cultivar's country of origin does not exclude it when it is widely grown or sold in the United States. The product should describe the collection as curated, never as a complete list of all apple cultivars.

## Record rules

- One row represents one apple variety, not a brand, orchard, packer, or color strain.
- Branded names are recorded as aliases when they identify the same cultivar. For example, `Pink Lady` is an alias for `Cripps Pink`.
- Search aliases are normalized for punctuation, capitalization, and common alternate spellings.
- Cultivar, brand, and trademark status need legal/editorial verification before a record becomes public.
- A catalog administrator can add, edit, merge, or hide records. Regular users cannot.

## Required fields before publishing

- `apple_id`
- Canonical name
- Search aliases
- Primary use or uses
- Short description
- At least one editorial source
- Image rights status and accessible alt text
- Active/hidden status

## Optional enrichment fields

- Country and region of origin
- Parentage
- Harvest season
- Sweetness, tartness, crispness, and juiciness
- Flesh color, skin color, and storage notes
- Cider classification

Flavor traits should be treated as editorial descriptors, not laboratory measurements. They can be refined after user testing.

## Sources and review process

Use U.S. Apple Association variety material for common U.S. varieties and regional association references for local use and seasonal notes. The New York Apple Association's usage chart is a useful cross-check for cooking, eating, and sauce classifications. Research staff should record the source URL and review date on every publishable record.

Before activation, review every candidate for:

1. Canonical naming and aliases.
2. Duplicate or near-duplicate records.
3. Appropriate primary use classification.
4. Image permission and attribution.
5. Brand and trademark display requirements.

## Expansion policy

Add varieties in curated batches, beginning with repeated U.S. user demand. Each batch should preserve the one-record-per-variety rule. Never allow an unreviewed suggestion to appear in search or receive rankings.
